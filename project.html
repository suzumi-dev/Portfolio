Adaptive trafic signal control system

This project focuses on developing an adaptive traffic signal control system that can adjust to varying traffic conditions in real-time.

How I built it :

  1. I define the whole system structure and what is needed
  2. classify each steps into clear and executed pattern
  3. Introduction of the system in short paragraphs
  4. Count the numbers of vechiles in each lanes (north , south ,east and west)
  5. Based on the result give traffic pass to the lane that has the large number of vechiles
  6. when it encouter two lanes with the same number of vechiles ,give priority to the lane that has emergency vechile.
  7. If the number of vechiles is equal in two different lanes without emergency lane ,it executes to the first vechile it encounter.

Technologies used to built this system:

  • complier
  • codeblock to display the result
